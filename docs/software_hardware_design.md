# Software ออกแบบวงจรฝั่ง Hardware

โปรแกรมสำหรับออกแบบวงจรอิเล็กทรอนิกส์ ตั้งแต่ Schematic ไปจนถึง PCB Layout

---

## **1. Fritzing**

### **คุณสมบัติ**

- **ประเภท:** Breadboard + Schematic + PCB
- **ระบบปฏิบัติการ:** Windows, macOS, Linux
- **ราคา:** ฟรี (Open Source) / €8 (สนับสนุน)

### **ข้อดี**

- ง่ายที่สุดสำหรับผู้เริ่มต้น
- มี Breadboard View (เห็นภาพจริง)
- มี Library ชิ้นส่วน Arduino เยอะ
- Export เป็น PDF, PNG ได้

### **ข้อเสีย**

- ไม่เหมาะกับวงจรซับซ้อน
- PCB Layout ทำได้แต่ไม่ดีเท่า
- ช้าเมื่อชิ้นส่วนเยอะ

### **เหมาะกับ**

- ผู้เริ่มต้น
- สร้างภาพประกอบโปรเจกต์
- วงจรง่ายๆ

---

## **2. KiCad**

### **คุณสมบัติ**

- **ประเภท:** Schematic + PCB + 3D Viewer
- **ระบบปฏิบัติการ:** Windows, macOS, Linux
- **ราคา:** ฟรี (Open Source)

### **ข้อดี**

- ฟรี 100% ไม่มีข้อจำกัด
- Professional Grade
- มี 3D Viewer
- Export Gerber ได้ (ส่งโรงงาน)
- Community ใหญ่

### **ข้อเสีย**

- ซับซ้อนกว่า Fritzing
- ต้องเรียนรู้

### **เหมาะกับ**

- โปรเจกต์จริงจัง
- ผู้ที่ต้องการส่งผลิต PCB
- มืออาชีพ

---

## **3. EasyEDA**

### **คุณสมบัติ**

- **ประเภท:** Schematic + PCB (Web-based)
- **ระบบปฏิบัติการ:** ทุกระบบ (ใช้ผ่าน Browser)
- **ราคา:** ฟรี (มีข้อจำกัด) / Pro ($100/ปี)

### **ข้อดี**

- ใช้ผ่าน Browser ไม่ต้องติดตั้ง
- มี Library เยอะมาก (LCSC)
- สั่งผลิต PCB ได้ทันที (JLCPCB)
- Auto-routing

### **ข้อเสีย**

- ต้องมีอินเทอร์เน็ต
- ข้อมูลเก็บบน Cloud

### **เหมาะกับ**

- ผู้ที่ต้องการสั่งผลิต PCB
- ไม่อยากติดตั้งโปรแกรม
- ใช้ชิ้นส่วนจาก LCSC

---

## **4. Eagle (Autodesk)**

### **คุณสมบัติ**

- **ประเภท:** Schematic + PCB
- **ระบบปฏิบัติการ:** Windows, macOS, Linux
- **ราคา:** ฟรี (จำกัด 2 Layers, 80 cm²) / $100/ปี

### **ข้อดี**

- มาตรฐานอุตสาหกรรม
- Library เยอะ
- มี Auto-routing
- Integration กับ Fusion 360

### **ข้อเสีย**

- ราคาแพง (Full Version)
- ซับซ้อน

### **เหมาะกับ**

- บริษัท
- งานอุตสาหกรรม

---

## **5. Altium Designer**

### **คุณสมบัติ**

- **ประเภท:** Schematic + PCB + Simulation
- **ระบบปฏิบัติการ:** Windows
- **ราคา:** $7,000+ (แพงมาก)

### **ข้อดี**

- Professional ที่สุด
- ฟีเจอร์ครบที่สุด
- มี Simulation
- มาตรฐานอุตสาหกรรม

### **ข้อเสีย**

- ราคาแพงมาก
- ซับซ้อนมาก

### **เหมาะกับ**

- บริษัทใหญ่
- งานอุตสาหกรรมระดับสูง

---

## **6. Proteus**

### **คุณสมบัติ**

- **ประเภท:** Schematic + Simulation + PCB
- **ระบบปฏิบัติการ:** Windows
- **ราคา:** $250-$1,500

### **ข้อดี**

- มี Simulation (Arduino, PIC, AVR)
- ทดสอบโค้ดได้โดยไม่ต้องมีบอร์ดจริง
- มี Library ไมโครคอนโทรลเลอร์เยอะ

### **ข้อเสีย**

- ราคาแพง
- Windows เท่านั้น

### **เหมาะกับ**

- การเรียนการสอน
- ทดสอบวงจรก่อนผลิต

---

## **7. Tinkercad Circuits**

### **คุณสมบัติ**

- **ประเภท:** Simulation (Web-based)
- **ระบบปฏิบัติการ:** ทุกระบบ (Browser)
- **ราคา:** ฟรี

### **ข้อดี**

- ฟรี 100%
- ง่ายมาก
- Simulate Arduino ได้
- ไม่ต้องติดตั้ง

### **ข้อเสีย**

- ไม่ได้ออกแบบ PCB
- เป็นแค่ Simulation

### **เหมาะกับ**

- ผู้เริ่มต้น
- เรียนรู้ Arduino
- ทดสอบโค้ดก่อนซื้อชิ้นส่วน
