# มาตรฐานอุตสาหกรรมในงานอิเล็กทรอนิกส์

มาตรฐานอุตสาหกรรมช่วยให้อุปกรณ์ต่างๆ ทำงานร่วมกันได้ มีความปลอดภัย และมีคุณภาพที่เชื่อถือได้

---

## **1. มาตรฐานแรงดันไฟฟ้า**

### **DC (Direct Current)**

| แรงดัน    | การใช้งาน                 | มาตรฐาน                           |
| -------- | ------------------------ | --------------------------------- |
| **3.3V** | ESP32, STM32, เซนเซอร์    | LVTTL (Low Voltage TTL)           |
| **5V**   | Arduino, USB, Relay      | TTL (Transistor-Transistor Logic) |
| **12V**  | รถยนต์, LED Strip, มอเตอร์ | Automotive Standard               |
| **24V**  | อุตสาหกรรม, PLC           | Industrial Standard               |
| **48V**  | PoE, Telecom             | IEEE 802.3af/at                   |

### **AC (Alternating Current)**

| แรงดัน    | ความถี่ | ประเทศ           |
| -------- | ----- | ---------------- |
| **110V** | 60 Hz | สหรัฐอเมริกา, ญี่ปุ่น  |
| **220V** | 50 Hz | ไทย, ยุโรป, เอเชีย |

---

## **2. มาตรฐานการสื่อสาร**

### **UART/Serial**

- **RS-232:** ±3V ถึง ±15V (ระยะ 15 เมตร)
- **RS-485:** Differential Signal (ระยะ 1.2 กม.)
- **TTL:** 0-5V หรือ 0-3.3V

### **I2C**

- **Standard:** 100 kHz
- **Fast Mode:** 400 kHz
- **Fast Mode Plus:** 1 MHz
- **High Speed:** 3.4 MHz

**มาตรฐาน:** NXP I2C-bus specification

### **SPI**

- **ความเร็ว:** ไม่จำกัด (ขึ้นกับชิป)
- **โหมด:** Mode 0-3 (CPOL, CPHA)

**มาตรฐาน:** Motorola SPI

### **CAN Bus**

- **ความเร็ว:** 125 kbps - 1 Mbps
- **แรงดัน:** Differential (CAN_H, CAN_L)

**มาตรฐาน:** ISO 11898

### **Modbus**

- **RTU:** Binary (UART/RS-485)
- **ASCII:** Text-based
- **TCP/IP:** Ethernet

**มาตรฐาน:** Modbus Organization

---

## **3. มาตรฐาน USB**

| เวอร์ชัน       | ความเร็ว    | กำลังไฟ            | การใช้งาน             |
| ------------ | ---------- | ---------------- | -------------------- |
| **USB 1.1**  | 12 Mbps    | 2.5W (5V, 500mA) | เมาส์, คีย์บอร์ด         |
| **USB 2.0**  | 480 Mbps   | 2.5W (5V, 500mA) | Flash Drive, Arduino |
| **USB 3.0**  | 5 Gbps     | 4.5W (5V, 900mA) | Hard Disk            |
| **USB-C PD** | 10-40 Gbps | 100W (20V, 5A)   | Laptop, Monitor      |

**มาตรฐาน:** USB-IF (USB Implementers Forum)

---

## **4. มาตรฐานไร้สาย**

### **WiFi**

| มาตรฐาน      | ความถี่     | ความเร็ว  | ระยะ  |
| ------------ | --------- | -------- | ----- |
| **802.11b**  | 2.4 GHz   | 11 Mbps  | 100 m |
| **802.11g**  | 2.4 GHz   | 54 Mbps  | 100 m |
| **802.11n**  | 2.4/5 GHz | 600 Mbps | 150 m |
| **802.11ac** | 5 GHz     | 1.3 Gbps | 100 m |

**มาตรฐาน:** IEEE 802.11

### **Bluetooth**

| เวอร์ชัน      | ระยะ     | กำลังส่ง       | การใช้งาน             |
| ----------- | -------- | ----------- | -------------------- |
| **Classic** | 10-100 m | 1-100 mW    | Audio, File Transfer |
| **BLE 4.0** | 50 m     | 0.01-10 mW  | Wearable, Sensor     |
| **BLE 5.0** | 200 m    | 0.01-100 mW | IoT, Mesh            |

**มาตรฐาน:** Bluetooth SIG

### **LoRa**

- **ความถี่:** 433/868/915/923 MHz
- **ระยะ:** 2-15 km
- **กำลังส่ง:** 14-20 dBm

**มาตรฐาน:** LoRa Alliance

---

## **5. มาตรฐานความปลอดภัย**

### **IP Rating (Ingress Protection)**

| รหัส      | ความหมาย                       |
| -------- | ------------------------------ |
| **IP20** | ป้องกันฝุ่นขนาดใหญ่ ไม่กันน้ำ           |
| **IP44** | กันฝุ่น กันน้ำกระเซ็น                 |
| **IP65** | กันฝุ่นสนิท กันน้ำพุ่ง                  |
| **IP67** | กันฝุ่นสนิท จุ่มน้ำได้ (1 เมตร, 30 นาที) |
| **IP68** | กันฝุ่นสนิท จุ่มน้ำได้ลึก                |

**มาตรฐาน:** IEC 60529

### **CE (Conformité Européenne)**

- รับรองความปลอดภัยในยุโรป
- ครอบคลุม: EMC, LVD, RoHS

### **FCC (Federal Communications Commission)**

- รับรองอุปกรณ์ไร้สายในสหรัฐอเมริกา
- ควบคุมการแทรกสัญญาณ (EMI)

### **UL (Underwriters Laboratories)**

- รับรองความปลอดภัยด้านไฟฟ้า
- ป้องกันไฟไหม้และไฟช็อต

---

## **6. มาตรฐานสีสายไฟ**

### **AC (ไฟบ้าน)**

| สี              | ความหมาย              |
| -------------- | --------------------- |
| **น้ำตาล/แดง**   | Live (L) - สายไฟเข้า   |
| **น้ำเงิน**       | Neutral (N) - สายกลาง |
| **เขียว/เหลือง** | Ground (E) - สายดิน    |

### **DC (ไฟตรง)**

| สี         | ความหมาย     |
| --------- | ------------ |
| **แดง**   | บวก (+)      |
| **ดำ**     | ลบ (-) / GND |
| **เหลือง** | สัญญาณ        |

**มาตรฐาน:** IEC 60446

---

## **7. มาตรฐานการผลิต PCB**

### **IPC Standards**

- **IPC-A-600:** มาตรฐาน PCB ที่ยอมรับได้
- **IPC-2221:** การออกแบบ PCB ทั่วไป
- **IPC-6012:** คุณภาพ PCB (Class 1, 2, 3)

### **ความหนาทองแดง**

| ความหนา  | การใช้งาน           |
| -------- | ------------------ |
| **1 oz** | งานทั่วไป (35 µm)    |
| **2 oz** | กระแสสูง (70 µm)    |
| **3 oz** | อุตสาหกรรม (105 µm) |

---

## **8. มาตรฐาน RoHS**

**RoHS (Restriction of Hazardous Substances)**

ห้ามใช้สารอันตราย 6 ชนิด:
1. ตะกั่ว (Lead)
2. ปรอท (Mercury)
3. แคดเมียม (Cadmium)
4. โครเมียม 6 (Hexavalent Chromium)
5. PBB (Polybrominated Biphenyls)
6. PBDE (Polybrominated Diphenyl Ethers)

**มาตรฐาน:** EU Directive 2011/65/EU
