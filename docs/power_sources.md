# แหล่งจ่ายพลังงาน: แบตเตอรี่ที่นิยมใช้งาน

ในปัจจุบัน แบตเตอรี่แบบชาร์จได้ที่นิยมใช้ในงานอิเล็กทรอนิกส์และหุ่นยนต์ในบ้านเรามีหลักๆ 2 ประเภท

## 1. แบตเตอรี่ 18650 (Lithium-ion)

มีลักษณะเป็นทรงกระบอก คล้ายถ่าน AA แต่มีขนาดใหญ่กว่า (เส้นผ่านศูนย์กลาง 18 มม. ยาว 65 มม.)

- **แรงดันมาตรฐาน (Nominal Voltage)**: 3.7V (ชาร์จเต็ม 4.2V) ต่อเซลล์ (S)
- **จุดเด่น**: หาซื้อง่าย, มีเคสใส่ (Battery Holder) สะดวก, ราคาประหยัด
- **การใช้งาน**: ไฟฉายแรงสูง, พาวเวอร์แบงค์, รถตัดหญ้าไฟฟ้า, หุ่นยนต์ขนาดเล็ก

เมื่อเราพูดถึง **Li-ion (Lithium-ion)** โดยเฉพาะในขนาด **18650** ซึ่งเป็นถ่านยอดนิยมที่สุดสำหรับงาน DIY (เช่น ทำพาวเวอร์แบงค์, แบตจักรยานไฟฟ้า หรือไฟฉายแรงสูง)

[**สิ่งที่ควรรู้และปัญหายอดฮิต**](power_sources_li-ion.md)

## 2. แบตเตอรี่ Li-Po (Lithium Polymer)

มีลักษณะเป็นก้อนสี่เหลี่ยม แบน หรือตามรูปทรงต่างๆ หุ้มด้วยฟอยล์นิ่ม

- **แรงดันมาตรฐาน (Nominal Voltage)**: 3.7V ต่อเซลล์ (S)
  - 1S = 3.7V
  - 2S = 7.4V
  - 3S = 11.1V
- **จุดเด่น**: จ่ายกระแสได้สูงมาก (High Discharge Rate - ค่า C), น้ำหนักเบาเมื่อเทียบกับความจุ
- **การใช้งาน**: โดรน (Drone), เครื่องบินบังคับ, ปืน BB Gun, อุปกรณ์ที่ต้องการความแรงและน้ำหนักเบา

[**สิ่งที่ควรรู้และปัญหายอดฮิต**](power_sources_li-po.md)
