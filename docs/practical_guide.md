# คู่มือการใช้งานเบื้องต้น

## การใช้งานโพรโทบอร์ด (Breadboard)

Breadboard ใช้สำหรับทดลองต่อวงจรโดยไม่ต้องบัดกรี

- **แถวข้าง (Power Rails)**: มักใช้เป็นขั้วบวก (+) และกราวด์ (-) เชื่อมถึงกันในแนวตั้ง
- **แถวกลาง (Terminal Strips)**: เชื่อมถึงกันในแนวนอน แบ่งเป็นสองฝั่ง

## การใช้มัลติมิเตอร์ (Multimeter)

มัลติมิเตอร์เป็นเครื่องมือวัดพื้นฐานที่ควรมี

1. **วัดแรงดัน (Voltage)**: ตั้งย่านวัด V และต่อขนานกับจุดที่ต้องการวัด
2. **วัดความต้านทาน (Resistance)**: ตั้งย่านวัด Ω และวัดที่ตัวอุปกรณ์ (ต้องไม่มีไฟเลี้ยงในวงจร)
3. **วัดความต่อเนื่อง (Continuity)**: ใช้เช็คว่าสายไฟขาดหรือไม่ (จะมีเสียง "ติ๊ด" ถ้าเชื่อมถึงกัน)
